Features · Polaris Client

What the client does

Polaris runs the official Kirka.io website in a focused desktop window and builds tools around it. Everything below happens on your machine, on top of the game — not inside it.

00 Ground rules

What Polaris will never do

  • No gameplay changes. Hitboxes, movement, damage and anything the server controls are untouched.
  • No automation. No aim assistance, triggers, macros or input scripting.
  • No anti-cheat bypasses. The game runs exactly as it does in a browser.
  • No currency. Nothing in the marketplace is sold or traded; KC, coins and game items are never involved.
