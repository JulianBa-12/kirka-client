01 Troubleshooting

Troubleshooting

The AppImage does not start

Check that the file is executable: chmod +x Polaris-Client-*.AppImage. Start it from a terminal to see the error. If it mentions FUSE, install libfuse2 (sudo apt install libfuse2 on Ubuntu 22.04 and newer).

The game view stays black or white

This is almost always the graphics driver. Turn off hardware acceleration in Settings → Performance, restart Polaris, and update your GPU driver. If the game also fails in a normal browser, the problem is on Kirka.io’s side.

Low or unstable FPS

Switch to the Performance profile, which turns off interface animations and animated backgrounds. The Performance view shows frame time, CPU and memory so you can see what changed. Lower FPS while the window is in the background is expected.

My crosshair or HUD overlay is not visible

Check that the overlay is enabled in Customization and that its opacity is above zero. Restyled game UI elements depend on the game’s own interface; after a Kirka.io update some may stop matching until Polaris is updated.

An update failed with a signature or checksum error

Do not try to work around it. The client refuses updates that are not signed with the Polaris key or do not match their published checksum. Retry later; if it keeps failing, download the current build from the downloads page, verify it with sha512sum, and file a bug report.

I can’t sign in to my Polaris account

If two-factor authentication is on, enter the six-digit code or one of your recovery codes. After several failed attempts sign-in is rate-limited for about a minute. During maintenance, sign-in and community features are paused while downloads keep working.

My upload doesn’t appear in the gallery

Uploads are reviewed by moderators before they are public. You can see the status of your uploads on the community page while signed in.

Where do I find the log file?

In the client: Settings → Advanced → Logs. Attach it to bug reports — it contains no passwords or tokens.
