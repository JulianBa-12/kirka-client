01

Install on Linux

Polaris ships as an AppImage that runs on most distributions, and as a DEB package for Debian, Ubuntu and their derivatives. Get the current build from the downloads page.

AppImage

  1. Move the file somewhere permanent, for example ~/Applications.
  2. Make it executable: chmod +x Polaris-Client-*.AppImage
  3. Run it: ./Polaris-Client-*.AppImage

If nothing happens and the terminal mentions FUSE, install libfuse2 (on Ubuntu 22.04 and newer: sudo apt install libfuse2).

DEB package

Install with sudo apt install ./polaris-client_*_amd64.deb. Polaris then appears in your application menu.

02

Verify a download

The downloads page lists a SHA-512 checksum for every file. Before running a new download, compare it with what your system computes:

sha512sum Polaris-Client-*.AppImage

The long hexadecimal string must match the one on the downloads page exactly. If it doesn’t, delete the file and download it again from the official page.

You only need to do this for the first install. Afterwards the client verifies every update itself: update manifests are signed, and the client refuses any manifest whose signature does not match the key built into it.

03

First launch

Polaris opens on Home. Press Play to load the official Kirka.io website in the game view. You play with your normal Kirka.io account — Polaris never asks for your game password.

A Polaris account is optional. You only need one to upload to the marketplace, vote on suggestions, use Social or sync settings between machines.

04

Crosshair Studio

Open Customization → Crosshair. Start from one of the official presets (Polaris, Classic White, Dot only, Ring, T-Style, North Star, Pulse) and adjust shape, size, thickness, gap, colour, outline and centre dot. The preview updates live.

  • Export saves the crosshair as a JSON file you can share or upload to the resource library.
  • Import loads a crosshair JSON from someone else.
  • Animated styles look nice in menus but a static crosshair is easier to read in fights.

05

HUD Editor

Open Customization → HUD to place Polaris overlays — FPS counter, latency, session timer and clock — by dragging them in the preview. Each overlay has its own size, opacity, colour and background.

The editor can also restyle supported parts of the game interface such as the kill feed, scoreboard and weapon info. That only changes how they look on your screen; the game itself is not modified.

Two official presets are included: Polaris Default and Minimal (FPS only).

06

Skin Studio

Skin Studio is a layered pixel editor for 64×64 and 128×128 templates. Use layers for base colours, shading and details so you can change one without repainting the others. Undo history covers every stroke.

  1. Create a new skin from a template.
  2. Paint, then export it as PNG.
  3. Share it from the client marketplace or the skin gallery.

Skins are cosmetic and local: they change what you see, not what other players see.

07

Performance

The Performance view shows measured FPS, frame time, memory and CPU. Pick a profile that suits your machine:

  • Performance — no interface animations or animated backgrounds, unlocked frame rate. Best for older laptops.
  • Balanced — light animations, unlocked frame rate. The default.
  • Quality — all interface effects with a VSync-locked frame rate for smooth pacing.

If the frame rate drops when the window is in the background, that is background throttling working as intended.

08

Smart Profiles

A profile bundles a performance profile, a HUD preset and a crosshair. The official ones are Competitive, Casual, Minimal, Performance and Practice. Switch between them in Profiles, or save your current setup as a new one.

09

Updates & channels

The Update Center checks for new versions regularly and downloads verified updates in the background. Choose the channel in its settings:

  • Stable — what we recommend for everyone.
  • Beta — new features earlier, with more rough edges. Beta builds may be rolled out gradually.

Every release and its notes are in the changelog.

10

Account & cloud sync

Create a Polaris account in the client or on the community page. With Cloud Sync on, your profiles and settings follow you to other machines. Conflicts are never overwritten silently — the client asks which copy to keep.

Protect your account with two-factor authentication in Settings → Account. From there you can also see active sessions, export your data or delete the account.
